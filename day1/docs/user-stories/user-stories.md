# Tailor Shop Management System
## User Stories

### 1. Admin / Shop Owner

#### User Story 1
As an Admin, I want to login securely so that I can access the management system.

#### User Story 2
As an Admin, I want to manage customer records so that customer information is organized.

#### User Story 3
As an Admin, I want to manage customer measurements so that accurate measurements are available for orders.

#### User Story 4
As an Admin, I want to maintain measurement history so that previous measurements are not lost.

#### User Story 5
As an Admin, I want to manage tailoring services and prices so that services can be maintained easily.

#### User Story 6
As an Admin, I want to create and manage orders so that customer orders can be tracked.

#### User Story 7
As an Admin, I want to update order status so that I can track the tailoring workflow.

#### User Story 8
As an Admin, I want to record customer payments so that payment records are maintained.

#### User Story 9
As an Admin, I want to view reports so that I can understand shop performance.

#### User Story 10
As an Admin, I want to manage staff information so that staff records are organized.

### 2. Tailor / Staff

#### User Story 11
As a Staff member, I want to login to the system so that I can perform authorized work.

#### User Story 12
As a Staff member, I want to view customer information so that I can work on customer orders.

#### User Story 13
As a Staff member, I want to add and update measurements so that correct measurements are used.

#### User Story 14
As a Staff member, I want to view assigned orders so that I can complete tailoring work.

#### User Story 15
As a Staff member, I want to update order status so that the current work progress is recorded.

#### User Story 16
As a Staff member, I want to view payment information when authorized so that I can understand order payment status.

### 3. Customer

#### User Story 17
As a Customer, I want to login securely so that I can access my account.

#### User Story 18
As a Customer, I want to view my profile so that I can check my personal information.

#### User Story 19
As a Customer, I want to view my saved measurements so that I do not need to provide them repeatedly.

#### User Story 20
As a Customer, I want to view my orders so that I can track my tailoring work.

#### User Story 21
As a Customer, I want to view order status and delivery date so that I know when my order will be ready.

#### User Story 22
As a Customer, I want to view my payment details so that I can check paid and pending amounts.

#### User Story 23
As a Customer, I want to receive order and payment notifications so that I stay informed.

### 4. Common User Stories

#### User Story 24
As a user, I want clear success and error messages so that I understand what happened.

#### User Story 25
As a user, I want a responsive interface so that I can use the system on desktop, tablet and mobile devices.
